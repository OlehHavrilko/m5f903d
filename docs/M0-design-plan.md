**Проект:** `Car → Atom` — интерактивный 3D-разбор автомобиля
**Объект по умолчанию:** `bmw-m5-f90` (BMW M5 Sedan F90 Competition, 2021)
**Статус:** M0 (план без кода, до подтверждения)
**Дата:** подготовлено в рамках текущей сессии

## 1. Что делаем (одним абзацем)

Одностраничное веб-приложение (TypeScript + three.js + Vite, без фреймворков), в
котором **одна непрерывная камера** пролетает от автомобиля целиком до атома
железа внутри коленвала. Это не просмотрщик модели, а объяснение «как устроена и
работает машина»: на каждом масштабе раскрывается ровно одна физическая идея.
Ни одного скачанного ассета — вся геометрия, материалы и звук генерируются кодом.
Подача — **нейтральная белая студия-циклорама**: ни дороги, ни неба, ни декораций.

### 1.1. Дух референса (GPU → Atom)

Проверенный референс: <https://olehhavrilko.github.io/3dgpuanimation/>. Оттуда
берём планку:

- одна непрерывная камера, следующий масштаб **проявляется внутри предыдущего**
  (seam 0→1), без монтажной склейки;
- постоянная панель **«Насколько это точно?»** со списком упрощений и источниками;
- **линейка масштаба** с бытовыми якорями;
- процедурная геометрия, тесты без GPU, mobile-first, deep links на уровень/фазу.

Переосмысляем под автомобиль: ДВС — естественный «спуск вниз по масштабу»
(5 м → 0,25 нм), а независимые системы (АКПП, подвеска, тормоза/руление) требуют
**хаба с ветками**.

## 2. Архитектура опыта: «спина» + ветки

```
SPINE (единая непрерывная камера)
  S-1  studio        12 м   машина в белой студии, турнтейбл (attract)
  S0   car            5 м   автомобиль целиком, хотспоты систем
  S1   body          2.5 м  кузов и силовая структура (панели снимаются)
  S2   chassis-hub   1.2 м  днище и агрегаты — ХАБ выбора ветки
                     ↓ выбор ветки (это обычный зум, не телепорт)
  ┌─────────────┬─────────────┬─────────────┬──────────────┐
  │ A. ДВС      │ B. АКПП     │ C. Подвеска │ D. Тормоза/  │
  │ 0.6 → 2.5e-10│ 0.15 → 1e-6│ 0.5 → 2e-4  │ руль 0.3→0.02│
  └─────────────┴─────────────┴─────────────┴──────────────┘
   (опционально E. xDrive, F. тепловой контур, G. EV)

Выход из ветки — обратный зум в хаб; breadcrumb: Автомобиль ▸ ДВС ▸ Один цилиндр
```

### 2.1. Правила бесшовности

1. **Внутри ветки** — приём референса: similarity-преобразование камеры
   (перенос + равномерный зум) и проявление следующего уровня *внутри* текущего
   (`seam 0→1`, кросс-фейд LOD + совмещение «якорной детали» в кадре).
2. **Вход в ветку** — непрерывный зум: из хаба (1,2 м) камера «въезжает» в
   агрегат (0,6 м у ДВС, 0,15 м у АКПП). Никакого скачка масштаба.
3. **Выход из ветки** — обратный зум + breadcrumb. `Esc` / свайп вниз — на
   уровень выше, `Backspace` / Home — в хаб.
4. **Deep links:** `#l=engine.cylinder&p=0.42&lang=ru` (ветка, уровень, прогресс,
   язык). Позиция и язык сохраняются при переключении языка.

### 2.2. Модель камеры

- Единая орбитальная камера (orbit + dolly + pan) с ограничителями.
- Пара «уровень → уровень» описывается как `similarity`: масштаб `s`, поворот
  `R`, перенос `t`, и **якорная точка** `A` (деталь, которая остаётся в кадре на
  обоих уровнях). Переход интерполируется по `u ∈ [0,1]` так, чтобы якорь не
  «прыгал» в экранных координатах.
- Ограничение «пола/стен» циклорамы: камера не уходит под горизонт сцены, кроме
  уровней, где это осмысленно (`chassis-hub`, подвеска, `susp.fluid`).
- `prefers-reduced-motion`: дрейф и вспышки выключаются, переходы становятся
  короткими dissolve.

### 3.6. Опциональные ветки (после MVP)

- **E. Привод/xDrive:** раздатка → муфта → карданы → редукторы → активный
  дифференциал → torque vectoring.
- **F. Тепловой контур:** ОЖ, радиаторы, маслокулер, интеркулер, термостат, карта
  прогрева.
- **G. EV:** drive unit → батарейный модуль → ячейка → катод → ион лития
  (сравнение ДВС/EV). Замыкает приложение на параллель с GPU → Atom.

### 6.1. Бюджеты (из §11)

- Начальный JS ≤ 320 КБ gzip; каждая ветка ≤ 120 КБ gzip (code-splitting).
- 60 fps desktop / ≥30 fps средний телефон; ≤300 draw calls; adaptive DPR;
  инстансинг + LOD; MSAA off на `low`; пост-обработка в half-res.
- Три тира: `low` / `mid` / `high` — автоопределение + ручной переключатель.
- `?debug` — только там включаются профайлер и `readPixels()`; в проде — ничего.

### 6.2. Детерминизм (§8)

- Один источник времени, фиксированный seed, **никаких `Math.random()` /
  `Date.now()` внутри кадра** (визуальные тесты и бенчмарки).
- `VehicleState` (rpm, gear, throttle, brake, speed, steering, ходы подвески,
  температуры, torqueSplit, crankAngle 0…720) — общее состояние для всех уровней.
- Пресеты: `idle`, `launch`, `dyno-pull`, `cruise`, `corner+bump`, `upshift`,
  `hard-braking`. Slow-mo и пошаговое проигрывание для тактов и переключений.
- `Space` — пауза, `[`/`]` — скорость, `,`/`.` — шаг по кадрам.

## 7. Визуальный язык (§9) — краткое закрепление

- **Фон:** ровный белый; пол — мягкая циклорама с ловящей тенью, не «дорога».
  Переключатель: белый / нейтрально-серый / чёрный; при разборе пол можно скрыть.
- **Свет:** процедурный 3-point (key/fill/rim) + мягкий градиентный ambient.
  Никаких HDRI-файлов. Contact shadow под машиной — дешёвая.
- **Читаемость на белом:** rim-light, AO, слегка тонированный пол — отдельный
  пункт приёмки, а не «само получится».
- **Разрез:** сплошные детали + штриховка среза; режим X-ray — полупрозрачные
  оболочки.
- **Цветовой код физики:** топливо — оранжевый, воздух/наддув — голубой, ОЖ —
  зелёный, масло — янтарный, выхлоп — красный, высокое напряжение — фиолетовый.
- **Линии потоков** с бегущими стрелками; масштаб стрелки = величине потока.
- **Линейка масштаба** с якорями: кузов → колесо → ладонь → монета → зуб шестерни
  → толщина волоса → эритроцит → масляная плёнка → атом.

## 8. UI/UX, a11y, SEO, i18n, аналитика (сводка §10, §12)

- Нижний бар: шкала + 5–6 кнопок, сетка, тап-таргеты ≥44 px,
  `env(safe-area-inset-*)`, `100dvh`, без горизонтального overflow на 320 px.
- **HUD рассчитан на белую сцену:** тёмные полупрозрачные стеклянные подложки,
  контраст ≥4.5:1 именно на белом (не только на тёмной теме).
- Режимы: Explore / Tour / Cutaway / Explode / Flow / Slow-mo / Compare / Dyno.
- **Compare:** V8 ↔ I4, «гидротрансформатор ↔ DCT», «двойной рычаг ↔ McPherson».
- Финальный Quiz («что произойдёт, если…»), «Share frame», «Star on GitHub».
- Тач: двойной тап — приблизиться, пинч — зум, свайп вниз — уровень выше, долгое
  нажатие — подсказка. Клавиатура: стрелки, `+/-`, `1–9`, `R`, `?`, `Shift+F`;
  `Space` не перехватывается на `<button>`; за интро-карточкой хоткеи выключены.
- **a11y:** семантика, ARIA для переключателей и live-region (смена масштаба
  озвучивается), `prefers-reduced-motion`, информация не только цветом,
  focus-visible, скрытые панели через `visibility:hidden`/`inert`.
- **Без 3D:** `guide/` — статическая страница на каждый уровень (a11y, no-JS, SEO).
- **SEO:** `robots.txt`, `sitemap.xml`, JSON-LD `LearningResource`/`WebApplication`,
  canonical, OG/Twitter (превью уровней оффскрин).
- **i18n:** `en`/`ru`/`uk` из одного словаря; язык сохраняет позицию и помнится.
- **Аналитика без cookie** (GoatCounter/Umami): `branch_enter`, `level_view`,
  `mode_switch`, `slowmo`, `quiz_answer`, `share_frame`, `guide_open`.

| Слой | Что проверяем |

| lint / format:check / typecheck | чистота кода |

не ломается; без WebGL — понятный экран, а не чёрный; `guide/` читается без JS.
