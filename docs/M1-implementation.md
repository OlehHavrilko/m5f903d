## 2. Как устроен бесшовный переход (seam)

1. Уровень задаёт камеру в **своих локальных метрах**: `camera.fovMeters`
   (диаметр кадра) и направление `from → to`. Дистанция вычисляется функцией
   `framingDistance()` так, чтобы объект влезал по меньшей стороне экрана —
   включая портретную ориентацию телефона.
2. `poseForLevel()` превращает это в мировую позу; `LevelManager` строит контент
   следующего уровня и запускает интерполяцию позы в `CameraRig`.
3. Пока камера едет, `seamBands(t)` кроссфейдит контент: уходящий уровень
   гаснет и слегка отъезжает, приходящий проявляется и «подрастает» на месте.
   После завершения уходящее дерево удаляется и освобождает GPU-ресурсы.
4. Отсюда — обещание непрерывности: следующий масштаб **проявляется внутри**
   предыдущего, без монтажной склейки.

Проверено юнит-тестами: `tests/unit/seam.test.ts`, `tests/unit/level-manager.test.ts`
(в т.ч. регресс-тест на «двойной t=1», который раньше обнулял прозрачность уже
осевшего уровня).

## 4. Тесты без GPU (`npm test`)

50 тестов в `tests/unit/`:

- `units` — перевод м → см → мм → мкм → нм, формат по языкам;
- `crank` — кинематика кривошипа, порядок работы V8 `1-5-4-8-6-3-7-2`, банки;
- `gearbox` — 8 передач ZF 8HP, круговой пересчёт rpm ↔ км/ч;
- `deeplink` — парсинг/сериализация, клампинг, устойчивость к мусору;
- `seam` — framing, кроссфейд-бэнды, интерполяция поз;
- `timeline` — детерминизм, диапазон угла коленвала, пауза/скорость;
- `levels` — валидация спеков и существование источников;
- `scene` — процедурный кузов и уровни строятся, геометрия конечна, диспоуз;
- `level-manager` — монтирование, оседание перехода, замена перехода на лету.

## 5. Известные ограничения (и когда закрываются)

- **Нет визуальных baselines и e2e.** В этом окружении Chromium из кеша
  Playwright не запускается (не хватает системных библиотек: `libnss3`,
  `libxkbcommon` и др.). Visual/e2e — M5–M6, интерфейсы `Stage`/`LevelManager`
  для них уже детерминированы.
- **Спина неполная:** есть `studio` и `car`; `body` и `chassis-hub` — M2.
- **Ветки A–D отсутствуют** (и это ожидаемо): M3–M5.
- **Режимы** Cutaway/Explode/Flow/Slow-mo/Compare/Dyno показаны, но выключены до
  соответствующих этапов.
- **Масса авто** помечена `unverified` (встречаются разные снаряжённые массы).
- Тексты уровней пока лежат в TS-спеках, а не в отдельном JSON; вынесение в
  `contentRefs` запланировано при появлении веток.

## 6. Как это посмотреть

```bash
npm install
npm run dev
```

- холодный визит → карточка-интро, затем бесшовный `studio ⇄ car` (стрелки,
  `←`/`→`, `Esc` вверх, `Home` — наверх, `R` — сброс кадра);
- `?debug` — счётчик fps, draw calls, треугольников;
- `?tier=low` — мобильный тир;
- `#l=car&p=0.5` — прямой переход на уровень;
- `F5` на белой сцене → без WebGL показывается экран с ссылкой на `guide/`.
